# SoccerManager Clone (The Next-Gen Online Football Manager)

> Un joc online de fotbal manager modern, corect (non-Pay-to-Win) și de mare profunzime tactică, construit pe matematica riguroasă a **SoccerProject**, completat cu uneltele inteligente native **SPINFO**, motorul de simulare probabilistic **RNG determinist cu Live Text Ticker & Timeline**, regulamentele reale din fotbalul modern **UEFA / FIFA**, generarea dinamică a pieței libere de transferuri, extinderea organică a diviziilor și dinamica socială a **Clanurilor**.
